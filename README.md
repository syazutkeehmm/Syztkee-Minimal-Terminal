# Syztkee Minimal Terminal

A clean and beginner-friendly terminal setup for Linux users.

## Features
- Simple and readable prompt
- Useful aliases
- Custom functions
- Easy install script

## Installation
git clone https://github.com/yourname/minimal-terminal-starter-kit.git
cd minimal-terminal-starter-kit
chmod +x install.sh
./install.sh
